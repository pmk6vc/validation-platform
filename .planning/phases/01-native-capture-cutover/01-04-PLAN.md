  <action>Define types: `EventKind int` with constants KindWrite=1, KindRead=2, KindClose=3. `Event{CgroupID uint64; PID, TGID, FD uint32; TsNs uint64; Kind EventKind; Data []byte}`. `Buffer struct{ writeBytes, readBytes []byte; reqQueue []*ParsedRequest; reqTimes []time.Time; lastActivity time.Time; cgroupID uint64 }`. `ReassembledPair{CgroupID uint64; Request *ParsedRequest; Response *ParsedResponse; LatencyNs int64; CapturedAt time.Time}`. Implement `Reassembler` with: `New(maxBodyBytes int, idleTTL time.Duration) *Reassembler`; `Feed(ev Event) []*ReassembledPair` (returns 0..N pairs produced by this event); `EvictIdle(now time.Time) int` (called periodically, returns count of evicted buffers, increments drops_aged_out). State per `(pid, fd)` key: append Data to writeBytes (KindWrite) or readBytes (KindRead). After each append, try to parse: ParseRequest on writeBytes → if success, enqueue to reqQueue + reqTimes, slice writeBytes. ParseResponse on readBytes → if success and reqQueue non-empty, pop head request, emit ReassembledPair with LatencyNs = now - reqTimes[0]. Pipelining detection: if len(reqQueue) > 1 when a Response parses, increment metrics.HTTPPairsDroppedTotal{reason="pipelined"} and drop the oldest queued request without pairing. KindClose: delete the (pid, fd) buffer; emit any in-flight unpaired-but-completed pair only if both writeBytes and readBytes parse cleanly, otherwise drop. Truncation: ParseRequest/ParseResponse already set Truncated=true on the parsed struct; metrics.HTTPPairsDroppedTotal{reason="truncated"} increments only when truncation discards readable content (cap exceeded). Write reassembly_test.go covering: synthetic write+read sequence on a single (pid, fd) produces one ReassembledPair; two concurrent (pid, fd) keys produce two pairs; close event invalidates the buffer (subsequent reads on same key don't emit); idle-TTL eviction produces aged_out counter increment; pipelined-write (two requests, one response) produces pipelined counter increment.</action>
